> **"Manage the future of space exploration."**
> OrbitManager est un tableau de bord interactif développé en **JavaScript Pur (Vanilla JS)** pour la gestion et le suivi des missions spatiales en temps réel.

## 🌌 Aperçu du Projet

Ce projet simule un centre de contrôle spatial. Il permet aux administrateurs de gérer une flotte de fusées, d'analyser les données de vol et de générer des rapports administratifs.

## ✨ Fonctionnalités Clés

* **🚀 Gestion de Flotte :** Ajout, modification et suivi du statut des fusées (En orbite, Lancement, Maintenance).
* **🌍 Support Multilingue (i18n) :** Interface traduite dynamiquement (Arabe / Français / Anglais).
* **📊 Rapports & Export :** Génération de rapports de mission téléchargeables en **PDF** et **Excel**.
* **📈 Data Visualization :** Graphiques et statistiques sur les performances des missions.
* **🔍 Recherche Avancée :** Filtrage rapide des missions par date, type ou statut.

## 🛠️ Stack Technique

* **Langage :** JavaScript (ES6+), DOM Manipulation.
* **Design :** CSS3 (Animations, Responsive Design).
* **Bibliothèques :**
    * `jsPDF` (Génération PDF)
    * `SheetJS` (Export Excel)
    * `Chart.js` (Graphiques)

## 🚀 Installation & Démarrage

Ce projet est statique et ne nécessite pas de backend complexe.

### 1. Cloner le projet
```bash
git clone [https://github.com/barakatyoussef/OrbitManager.git](https://github.com/barakatyoussef/OrbitManager.git)
cd OrbitManager
```
### 2. Lancer l'application
Il suffit d'ouvrir le fichier index.html dans votre navigateur.
*Recommandation : Pour une meilleure expérience (icônes, chargement JSON), utilisez l'extension Live Server sur VS Code.*
